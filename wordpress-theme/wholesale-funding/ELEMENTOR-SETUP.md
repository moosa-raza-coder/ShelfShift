# Wholesale Shelf - Elementor Page Builder Setup

Your WordPress theme is now **fully compatible with Elementor**, the #1 drag-and-drop page builder for WordPress.

## Quick Start (3 Steps)

### Step 1: Install WordPress + Elementor Plugin
1. Set up WordPress on your server
2. Install Elementor plugin: `Plugins → Add New → Search "Elementor" → Install & Activate`

### Step 2: Activate the Wholesale Shelf Theme
1. Go to `Appearance → Themes`
2. Activate "Wholesale Shelf Corporation" theme
3. The theme automatically supports Elementor

### Step 3: Import Homepage Template
1. Go to `Elementor → Templates → Import Template`
2. Upload: `elementor-templates/wholesale-shelf-homepage.json`
3. Click "Import"
4. Create a new page and apply the template

## How to Use the Template

### Import Method 1: Elementor UI
```
1. Admin Dashboard → Elementor → Templates
2. Click "Import Template"
3. Select "wholesale-shelf-homepage.json"
4. Click "Import"
5. View template in your library
```

### Import Method 2: Create New Page
```
1. Create a new page: Pages → Add New
2. Click "Edit with Elementor"
3. Click hamburger menu → Templates
4. Click "Import" → Upload JSON
5. Template loads and is ready to edit
```

### Import Method 3: Manual
```
1. Create a new page
2. Edit with Elementor
3. Add sections using Elementor's interface
4. Reference the template content as you build
```

## Troubleshooting

### Template won't import?
- Ensure Elementor plugin is installed & activated
- Check that theme is activated
- Try manual page building instead

### Elementor not working?
- Update to latest Elementor version
- Clear WordPress cache
- Check PHP version (7.4+ required)
- Disable conflicting plugins

### Styling issues?
- Clear browser cache (Ctrl+Shift+Delete)
- Rebuild Elementor styles (Tools → Regenerate)
- Check CSS conflicts
