# Elementor Templates for Wholesale Shelf

This directory contains Elementor page builder templates for easy WordPress page creation.

## How to Import

### Method 1: Using Elementor Import
1. Go to WordPress Admin → Elementor → Templates
2. Click "Import Template"
3. Upload the JSON file from this folder
4. Click "Import"

### Method 2: Elementor Plugin Import
1. Install Elementor Pro (or free version)
2. Create a new page
3. Open with Elementor
4. Click hamburger menu → Templates
5. Click "Import" 
6. Upload JSON file

### Method 3: Manual (Without Plugin)
1. Install and activate Elementor plugin
2. Create new page
3. Edit with Elementor
4. Use the template blocks as reference and build manually

## Available Templates

- `wholesale-shelf-homepage.json` - Complete homepage with all sections

## Customization in Elementor

Once imported, you can easily customize:
- Text content
- Colors and backgrounds
- Typography and spacing
- Button styles
- Image and media
- Forms
- Animations

Everything is drag-and-drop!

## Requirements

- WordPress 5.0+
- Elementor 3.0+
- PHP 7.4+
